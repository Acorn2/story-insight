# 阅读、分析与选题

## 用完整对话理解问题

目录任务先列文件清单，再逐篇读完；不要只读标题、开头或检索命中片段。长稿可分段读取，直到已读范围覆盖全文，工具输出被截断的部分必须补读。精剪后的对话只能说明保留部分，不能推断被删掉的背景。

关键分析至少回答：

- 来电者原本请求什么？后来新增的信息是否改变了问题性质？
- 主播回应了哪一个问题？有什么前提、例外或之后的调整？
- 来电者接受、纠正或反复追问了什么？双方是否实际达成一致？
- 有哪些可以保留的具体动作、关键原话、前后变化？它们为什么改变了选择或读者理解？
- 哪些只是寒暄、玩笑、个人评价，或不足以支撑独立文章？
- 哪些关键信息缺失，不能靠推理补全？

不要把反复追问一律解释为“不听劝”，把表达不清解释为能力缺陷，或只从主播视角判断谈话。保留不同当事人的诉求，不为戏剧性强行制造对立。

把变化连起来看：`最初诉求 → 回应及其前提 → 补充或纠正 → 回应的调整或仍未对上 → 未解决的问题`。这是一条阅读线索，不要求对话真的完成全部环节。建议回答的是生存、能力、意愿还是关系责任？当事人后来的补充有没有使原建议失去针对性？原稿没有后续结果时，停在未知处，不能推断其采纳、拒绝或获得成功。

独立故事需要理解这段互动的作用，不需要让虚构人物轮流复述原发言。把“某人给了什么建议”抽象成“外部信息能改变什么、不能替谁决定什么”，再独立创作。分析不能省略回应方，也不能把回应方塑造成永远正确的导师。

## 来源与定位

内部索引可写成：`S01：源文件 + 可得的版本信息；L20–L28；全文已读/已读范围`。只有段落可用时写“第 N 个发言段”，说明计数方法。关键原话保留足够短的核对片段，避免大量复制。

- 版本信息可复用已有指纹；没有指纹时注明未取得，不为此新增程序或假造版本号。
- Markdown 原稿若无时间，不能按字数推算时间，也不能把成片时间当作原视频时间。
- `说话人（未确认）` 可能包含多人的连续对话；分别记录内容线索和归属疑点，不猜成确定说话人再引用。
- 有必要确认归属时回查用户指定的可靠上游或原音；无法核对就不用直接引语。没有实际听审，不写“已视听复核”。
- 上游隐藏/替换记录如已提供则沿用适用范围；只看到“须遵守相关要求”而未取得具体要求时记为缺失，不声称已执行。

## 分开五类内容

| 类型 | 记录方式 | 不能做什么 |
|---|---|---|
| 当事人自述 | “其称/据其描述”，定位原文 | 把描述认定为实际发生，或直接认定第三人违法 |
| 主播观点 | 记录语境、条件及归属是否确定 | 当作事实、专业诊断或用户最终主张 |
| 外部可核查事实 | 链接原始材料并说明支持范围 | 用其他人的类似案例证实该连麦经历 |
| 作者分析 | 展示推理和限制 | 伪装成研究定论或编成用户亲身经历 |
| 虚构设定 | 独立创建并明确标示，核对内部因果及必要现实规则 | 反向归给真人，或用虚构结果证明现实主张 |

## 以读者问题组织候选题

原对话的处境、原话和来源位置只用于内部分析。选定议题后，保留所选困境在关系、行动及补充信息中的依据，再独立组织正文材料。不能把内部选题卡中的“故事角度”直接扩写成原人物故事；不默认把主播回应写成正文的推理路线。故事任务先理解人物，再形成暂定判断，避免先定道理、再安排人物接受它。

不要求固定数量。每个候选题保持一小段即可：

> **问题 / 读者**：谁遇到什么困惑？
>
> **故事角度**：谁想得到什么，遇到什么阻碍，哪条新信息使问题发生变化？
>
> **入口 / 追问**：可用哪个动作、细节或反常后果开场，读者想知道什么？
>
> **阅读回报 / 暂定主张**：故事靠怎样的悬念、关系变化或感受值得读？不必先定教训；议题文章准备说明什么，是否只是主播观点的重复？
>
> **论证边界**：提出现实主张时，什么反例或条件会限制它？纯故事不强填反方观点。
>
> **依据 / 缺口**：原文定位、需独立核验的判断。
>
> **取舍**：推荐研究 / 备选 / 不建议；理由与素材用途限制。

优先保留有明确读者、材料依据且能展开的问题。议题文章看能否形成有证据的独立判断；故事看愿望、关系和应对能否带来持续好奇或情感变化，不因提炼不出人生道理而淘汰。没有足够信息的“反转故事”、泛泛金句、纯八卦和仅靠当事人痛苦吸引注意的内容不强行成题。来源权限不明时，不把独特情节改几个身份信息就当作一般问题。

“爱好与进步”只是主题，“越认真准备，越迟迟不愿开始”才出现可以推进的角度。角度必须有材料支撑，不能把每次学习都写成拖延。先保存具体关系及其依据，再判断哪些可以用于正文；不要在分析时就把所有人物动作压缩成“建立边界、保持自我”等万能词。

材料用途分开处理：源对话具体处境保留在内部；独立找到的公开案例另核对其来源与适用范围；虚构场景独立重建具体事件，不保留可识别的人物网络、具体经历链与稀有细节组合。一般关系张力和因果认识可以迁移，不能把保护隐私理解为消除所有关联。不把原案换名或多人拼接称为合成场景，也不因为原案不可回放就要求文章只能剩抽象说理。

一段长谈可能包含不同主题，按论证问题拆分，不用全文的主标题强行覆盖全部内容。多个案例可以聚合共同议题，但不得合并人物、时间线和结局；共鸣也不等于普遍发生率。

## 指定素材的故事：说明保留与重建

用户给定稿件要求另写故事时，在现有创作记录中用一小段或简表说明以下内容，不另建必交文件：

| 内容 | 要说明什么 |
|---|---|
| 原文依据 | 哪些行为、补充或回应支持本篇选定的困境，定位到原文；未知的部分仍未知 |
| 创作理解 | 怎样理解人物在乎的关系、犹豫或损失；将推断与明确自述分开，不假定心理已被证实 |
| 保留部分 | 新故事要让读者经历哪一种关系或选择困难，哪条信息改变了对它的理解 |
| 重建部分 | 新人物与关键事件怎样承载它；哪些动机、起因和后果是新设，为什么没有改写主线 |

新故事只需选清一条有依据的核心，不必迁移全稿所有主题、原发言次序或每条建议。用户只借主题自由创作时注明范围，不强求紧密对应。

“仍在联系”可以是原文行为，“害怕承认失去关系”可能只是创作解读；后者可以成为新人物的动机，不能反向写成原当事人的内心。具体创作规则见 [story-craft.md](story-craft.md)。

### 用对照校准关联尺度

以下全部为合成教学材料，不来自私人原稿。假定选定核心是：人物想退出共同投入的活动，一次成功减轻了能力顾虑，但没有回答是否愿意继续；退出还会影响已答应同伴的事。

| 候选设计 | 判断依据 | 下一步 |
|---|---|---|
| 把合成原案的乐团改名换城，仍按同一顺序写临时缺席、雨中演出、后台争执及原对白 | 困境尚在，但具体事件链仍是原案载体；改名和虚构标记不足以说明独立性 | 重建事件与关系中的实际应对，不只更换外观 |
| 写一个陌生人独自参赛，夺冠后找回信心 | 同样有关“能力与兴趣”，但退出意愿和对同伴的承诺消失，核心问题已变 | 若用户未授权只借主题，回到所选困境 |
| 写两人共同维护的小展览，主人公完成一次困难讲解后仍决定减少投入，另一人要求重新谈已约定的轮值 | 起因、场景与应对另建，能力、意愿和承诺仍影响关键选择；这是候选设计，不是自动通过 | 再核对原文是否支持所选核心，以及具体人物网络和事件组合是否独立 |

关联检查问“哪些关系与选择逻辑仍在”，独立性检查问“新故事靠哪些不同事件使它发生”。两项分别判断。上述三要素只服务这个例子，不要求别的素材也围绕退出、成功或承诺，更不要求新故事逐场映射原对话。

## 语义判断示例

以下是合成判断示例，帮助理解边界，不规定所有素材必须提取相同选题：

- 从“朋友不再来往”到“反复辱骂、影响正常出门”：不能只用“接受关系变化”概括全过程。
- 聊天中“我认识你的老师”伴随明显玩笑：不能据此建立真实认识关系。
- 主播建议“了解当地就业支持”：形成研究问题，不直接写成某地必然存在、当事人一定符合资格的政策指南。
- 从“现金能支撑多久”转到“买房”和“生育”：拆开不同决策，不把同一套建议推广给全部人群。
- “有亲密关系所以状态好了”：只能作为谈话中的推断，不能推出健康诊断或康复结论。
- 一段关于普通爱好的轻松交流：可以只保留素材观察；不必为了目录齐整生成一篇文章。

## 风险影响用途，不替代选题质量

对未成年人、健康、私生活及严重指控，先判断文章是否真的需要使用个案。通常可转向已独立确立的一般问题；不能兼顾事实、署名和个人权益时，暂停个案引用。低敏感、表达平和也不自动说明授权和事实都无问题。

“批量分析”“全流程”只覆盖已指定的素材和任务阶段，不授权额外采集评论、搜索当事人、对外上传或公开传播。
