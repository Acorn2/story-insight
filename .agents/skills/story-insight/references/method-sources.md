## 文风编辑

以下文件在 2026-10-23 实际阅读，按本项目边界独立整理方法。链接用于维护追溯，执行本 Skill 无需联网加载或安装上游。

- [human-writing：revision](https://github.com/KKKKhazix/human-writing/blob/4fda173f3fef7fb808f3eba991eeb2528ea4b189/human-writing/references/revision.md) 与 [forum-prose](https://github.com/KKKKhazix/human-writing/blob/4fda173f3fef7fb808f3eba991eeb2528ea4b189/human-writing/references/forum-prose.md)（MIT）：参考先保护已有声音、删重复解释、区分假具体与假口语、检查中文语序照应及自然停笔。翻案按修辞作用判断，不能靠换词绕过；不采用全面禁用标点、改写真实引文、固定七遍、删除比例或脚本门禁，保留本项目的事实与文体边界。
- [sepia：narrative-pass](https://github.com/Nanako0129/sepia/blob/d9b292c1ec8daa893e48dd60ccc07d226a75404c/skills/sepia/references/narrative-pass.md)（MIT）：参考过度点题、机械收束、重复情绪表达的诊断，以及不把所有手法叠加到一篇故事。不移植结构比例、固定手法数量、强加支线或刻意打断因果等处方。
- [oh-story-claudecode：story-deslop](https://github.com/zenstory-ai/oh-story-claudecode/blob/74080143dd1ac9a39a930fafd99a0dbbe61b946a/skills/story-deslop/SKILL.md)（MIT）：参考表达、用笔与故事的分层诊断，保留文风与既定剧情，修改后对照完整场景。不引入检查脚本、hooks、部署、作者记忆或多 Agent 编排。
- [creative-writing-skills：style-analysis](https://github.com/haowjy/creative-writing-skills/blob/fec5020a91dddd089d74a00a2d7b87f15a919ae4/skills/creative-writing-craft/resources/style-analysis.md)、[voice](https://github.com/haowjy/creative-writing-skills/blob/fec5020a91dddd089d74a00a2d7b87f15a919ae4/skills/story-review/resources/prose-critique/voice.md) 与 [failure-modes](https://github.com/haowjy/creative-writing-skills/blob/fec5020a91dddd089d74a00a2d7b87f15a919ae4/skills/writing-principles/resources/failure-modes.md)（Apache-2.0）：参考对白同质化、声音漂移、过度解释与过早消解紧张的检查。不复制示范句或把对模型训练的解释当作已验证事实。
