# 阅读体验与结构修改

用于起草后的阅读检查，以及用户反馈“不好读、没故事、开头留不住人”时的改稿。它与事实、归属及权益检查并行，不能互相代替。只有审查授权时报告问题，不擅自改写。

## 先确定在替谁读

沿用用户指定的目标读者。没有资料时，说明假设的读者所处情境、已有知识和阅读目的，例如“想在下班后找点乐子，但对自己的爱好总嫌不够好的普通读者”。不要凭空赋予其年龄、诊断或职业。

在当前会话中顺读成稿，暂时放下作者提纲，不靠提纲解释正文没写清的东西。记录的是对某类读者体验的推测，不是独立读者反馈、平台数据或心理测量；不需要额外 Agent、模型服务或分数。

先辨认这篇打算给读者什么：想看事情如何办成、享受相处的乐趣，还是感到紧张、刺痛或被理解。沿用文本与任务已有的取向，不要求每篇同时有笑点、悬念与启迪。事实解答另检查有没有说清问题与依据，不把小说的要求套给所有文章。

指定素材的故事读完后，复用创作记录中的保留与重建说明，检查人物在乎的东西、困难和关键选择是否仍对应所选核心。好读的另一篇故事也可能没有完成取材任务；不要求通过复刻原案来证明关联。

## 记录哪里改变了阅读意愿

关注有信号的位置，不强制每段填表：

- **完整性**：主要追问、关键行动和后果能否连起来？缺的是必要因果，还是本可留白的后续？完整不自动等于好看。
- **入口**：能否知道谁处于什么局面？刚读完是否还有一个具体问题想弄清？标题和开头是否许诺了正文没有兑现的内容？
- **持续吸引力**：入口的问题解释后，又在意谁会怎样应对？中途在哪里已猜到余下全部走向，之后是否只是在确认？相处与观察本身带来的乐趣也可以留人。
- **推进与详略**：哪条新信息改变了判断？同一经历换了听众后是否重复交代？最影响关系或选择的时刻有没有实际展开，篇幅是否耗在安排和转述上？
- **人物与选择**：能否理解其诉求和限制？反应是否属于这个具体的人，还是任何同类角色都会说的话？是否忽然跳出一个材料不支持的心理解释？
- **代价与关系**：人物在乎或舍不得什么？重要决定有没有影响其承诺、处境或与别人的关系？不同人物是否只是为了配合结论才改变意愿？
- **节奏与声音**：哪些细节可见、哪些解释需要重读、哪段像演讲或摘要？
- **收束与回报**：主要追问是否得到回应，哪里已足够停笔？之后还有新的后果，还是多次回扣和总结？触动、快乐或余味落在哪个具体反应上；没有启迪不因此判为缺点。

每条发现定位到段落或一句短引语，并写具体阅读信号，如“到这里已知道全部结论，下一段只重复”“忽然出现理论名词，还不知道它解释谁的困境”。不用“缺少感染力”“很有共鸣”代替定位。

## 将体验与诊断分开

先写体验，再解释可能原因，再决定修改。例如“读到这里走神”并不自动说明句子太长，也可能是上段已把问题答完。

| 阅读信号 | 回查什么 | 可选修改 |
|---|---|---|
| 第一段就知道全文要说什么 | 是否只给了常识结论，没有需要解释的变化 | 换动作、选择或反常后果入口，提前具体问题 |
| 有场景，马上又出戏 | 是否插入冗长编辑说明、身份说明或定义 | 保留必要标记与限定，其他移到记录；恢复场景推进 |
| 开头吸引，中段发平 | 入口的疑问是否早已回答，后续只在等待预定答案；相邻场景是否只让更多人知道同一件事 | 压缩已知信息，让既有行动引出的应对与代价进入正文；没有余下追问就收束，不临时造事故 |
| 最关心的一场戏很快过去 | 哪次回应最可能改变关系或选择，是否被概述，而安排、求助和安慰占了主要篇幅 | 把篇幅还给这次具体应对，写出前一句如何影响下一步；没有作用的回合不靠加长补足 |
| 事情讲完了，却不关心人物 | 是否只写处境和答案，读者不知道人物为何在意、舍不得什么 | 真人材料只用已有依据；虚构故事补能支撑选择的行为与关系经历 |
| 好读，但看不出为何来自指定素材 | 是否只剩宽泛主题，新增起因已改变人物受伤或犹豫的原因 | 回到保留与重建说明调整起因及关键选择，不只加一段感想；用户只借主题时不据此判错 |
| 尝试一成功，矛盾突然消失 | 成功解决的是能力、开销，还是人物真正的意愿或责任问题 | 对照最初诉求，写清尝试实际改变的部分，再处理选择与后果 |
| 对话像轮流讲道理 | 人物此刻想争取什么，是否都在替作者发言 | 让回应受各自处境影响，展开关键分歧，压缩重复的观点对白 |
| 道理明白，却感受不到人 | 感受是否一出现就被劝好，人物是否只剩“需要帮助者”“明理者”等功能 | 保留有处境依据的自私、留恋、改口或犹豫，让具体反应成立；不为复杂而添加缺陷或替伤害开脱 |
| 笑点多却不理解问题 | 类比是否映射真实关系，是否离题 | 先讲清关系，删装饰梗，回到对象 |
| 结尾像另一篇文章 | 主要追问是否回应，是否为了金句另起宏大话题 | 回到前文已建立的行动和关系后果，不强制回收开头物件 |
| 好像已经结束了几次 | 核心行动之后，是否反复用安慰、物件和总结确认同一感受 | 比较可能的停笔位置，保留必要后果，合并重复收束；有新意义的尾声和回环可以保留 |

不强制所有段落反转、所有开头讲故事或所有结尾押金句。读者要求的是清楚而有推进，不是固定套路。

审读时允许几个结论不一致：结构完整但持续吸引力弱，情节简单却因反应可信而动人，或有现实意义却说教过多。给出造成判断的具体位置，不能用一个总分遮住差别；没有证据不写“读者一定会感动”。

完整虚构故事另按 [story-craft.md](story-craft.md) 检查关键选择是否真正发生。开放结尾可以留下后续，不能只把决定推迟到故事之外；短假设和事实解答不必套用完整人物弧线。

## 改后再顺读

改结构优先于换近义词：重排节点、让具体细节承担作用，再调语气与句长。真人叙事只补材料支持的中间环节；独立虚构可以重建情节与动机，但需检查前提、时间、视角和因果是否一致。修改涉及现实事实、引语或证据时回到内容审校，不为了连贯新增真人细节。

在创作记录只保存最有用的几条“位置 → 体验 → 结构判断 → 实际改动”，以及仍存问题。没有真实用户反馈时明确待用户审阅；不能把模拟结论写成阅读率、留存提升或用户满意度。

只做评估时，按用户关心的维度给出具体依据、成立的部分及最影响阅读的改进顺序，不擅自生成改写稿。修改后回查同一处阅读阻力是否被处理，以及有分量的反应是否仍在；不能把“少了字、对白长了、回扣删了”本身当成效果证明。

故事与长文继续按 [natural-voice.md](natural-voice.md) 做去模板腔编辑；“愿意继续读”与“声音自然”分别判断，不把前者自动记成后者通过。有关声音的发现沿用当前定位与记录，不另做一份重复报告。
