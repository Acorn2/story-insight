# 内容审校与交付状态

这是项目编辑标准，不是对某篇素材的法律意见或平台通过承诺。只报告实际检查过的内容，未知项不得自动写为通过。

## 自审顺序

完整成稿沿用阅读体验与文风编辑的交接，最后核对下表适用项。只审查、事实解答与局部编辑按本次范围执行，不因为进入最终审校而重跑所有前置阶段。事实审校不把可用的动作和细节改成抽象道理。

本表负责事实、用途与交付边界。结构和声音已有结论则复用；发现新问题时指出需返回的阶段与受影响范围，不在这里展开另一轮全文润色。

| 检查 | 要找的问题 | 处理 |
|---|---|---|
| 默认议题边界 | 标题、正文、摘要、配图文案暴露主播、节目、场次、连麦或求助来源 | 默认独立议题稿退回重写，不能只删来源名称后放行 |
| 原案回放 | 删名后仍可对应可识别的人物网络、稀有细节及具体经历链，或把原案换名写成假设 | 更换具体叙事材料；一般关系张力可以保留，不能以消除关联代替独立构造，多人拼接也不能通过 |
| 取材关联 | 指定素材的故事只剩宽泛主题，新增起因改变了核心困境，或人物情感只能靠记录解释 | 按保留与重建说明回查原文依据及新故事的起因、行动和选择；关联不足则改设计，用户明确只借主题时沿用该范围 |
| 语境与归属 | 漏读、混合说话人、丢前提、只摘一方故事或建议、把玩笑当事实 | 回查诉求、回应及补充如何改变问题，无法确认就不用引语；未有的调整或后续留为未知 |
| 来源与用途 | 使用范围不明、把内部处理授权当成公开改编许可 | 记录缺口，暂停受影响用法，继续已可用的独立议题 |
| 个人权益 | 身份组合、第三人私事、未成年人或健康细节、单方指控 | 删除非必要细节；不能兼顾时停用个案 |
| 证据 | 来源只相关不支持、研究人群错配、因果外推、过期政策 | 补证、收窄或删除，不靠添加免责声明掩盖错误 |
| 真实与虚构 | 为真人编对白、动机或结局，多人拼成一人，独立虚构冒充亲历 | 真人材料删除无依据补写；独立虚构允许完整创造，明确标示并检查内部一致性，不反向归给原素材人物 |
| 处境与责任 | 年龄或身份变化抹平依赖和权力差距，把侵扰写成双方各退一步，要求先勇敢或原谅才配得到帮助 | 重建合理的求助条件与责任边界，不用一条导师金句代替保护或强迫和解 |
| 标题与配图 | 夸张结论、新增指控、暗示官方合作、把插画当纪实 | 重写标题或图意，标明示意及图片状态 |
| 去味后的保真 | 为显得像人新增经历、改变选择或揭露顺序，删去必要心理与限定，或将正文剪成短句串 | 对照基线与原有记录，恢复被误伤的信息和声音；不以禁词零命中或自评分替代顺读 |
| 虚构的论证范围 | 用故事结果证明现实建议有效，或认为标为虚构即可编造专业规则 | 现实推广另找证据，核对会改变情节及判断的现实规则；不要求为自创人物逐项查证 |
| 说明的放置 | 创作流程说明反复打断、关键限制却被移出正文 | 保留影响理解的限定及假设标记，其他放记录 |

对严重未证实指控、医学诊断及高敏感个案，不要为凑齐完整草稿保留问题段落。尽量交付可用的抽象问题分析，并明确不能得出的结论。

反向检索若确有必要，先避免将待保护信息泄露给搜索服务；不能安全执行则注明未做，采用更保守的省略方案。没有执行反向检索不能写“无法被识别”或“已经匿名”。

先离开原案单独顺读正文，判断人物和事件是否成立；再用内部记录核对取材关联及是否回放可识别的原经历。一般情感与因果的对应、具体细节的独立性分别判断，不把相似主题当作充分关联，也不把一切关系相似都判成复述。删去来源名称后仍在回放原经历，说明需要更换叙事材料，不是继续打码。独立引用的论文、统计及其他公开资料仍保留必要出处，不把隐私保护解释为一律不署名。

## 独立记录不同状态

按本次适用范围核对以下状态，在交付回复中简述影响使用的结果；用户要求记录时才另存。没有执行的项目不填“通过”，无关栏目省略：

- **输入**：覆盖范围、素材版本、说话人归属及已知上游限制。
- **证据**：实际查证了什么，仍缺哪些依据，对文章结论有何影响。
- **用途**：内部分析、个案引用、公开叙事各自的已知范围；无依据时写待核实。
- **编辑**：本次 AI 自审完成项、尚需用户或专业人员处理的事项。
- **阅读体验**：目标读者假设、具体位置的发现、实际结构改动及仍存问题；不当作真实读者数据。
- **文风编辑**：实际定位的机械感、代表性改前后对照、保留的有效写法及未解决处；不宣称已消除 AI 痕迹。
- **用户审阅/发布**：只记用户实际作出的决定及对应版本，不补签名、批准或发布链接。

无需建立评分、法律风险自动分类器或复杂工作流。低风险判断、另一模型复核和人工批准都不能弥补缺失的使用条件。

## 交付措辞

- 完成自审且没有关键缺证项：**已自审草稿，待用户审阅**。
- 关键事实仍不足：**待补证草稿**，列出具体缺口；能删除问题论证时先删并完成剩余稿件。
- 无法继续使用某个案：说明暂停的用法、理由、已完成内容和可继续的部分，不将整项任务一概判死。
- 只交配图策划：**图片未生成**；未联网则**外部事实未核验**；只读文本则**未视听核对**。

没有“已保证合规”“审核全部通过”“用户已批准”之类无依据结论。未经用户明确发布指令，不操作平台，也不要求用户为了获得草稿先批准发布。

## 修改后的复核

修改素材时重查引用、语境和归属；修改正文或更换证据时重查支持关系。标题、摘要、封面和配图有变化也要重新检查。引用旧审核记录时说明仍适用的范围，不能把新版本标成旧版本已审。

AI 使用说明必须符合实际流程。平台按钮、原创声明、版权条文、专业服务与地方政策均不在本文件中硬编码为永久规则；涉及公开发布或具体政策论证时再查当期官方来源，工具不足就标待核验。
