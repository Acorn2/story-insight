# 单篇视觉设定

本次执行复用一组简短的画风、角色和场景约束，不单独生成 `视觉设定.md`、角色卡或 prompt 文件。用户需要了解的设定可在 `配图说明.md` 中简述，不建立跨作品永久人物 IP。

- 风格：默认 `editorial-cinematic`，克制电影感插画；可按用户选 watercolor、realistic-illustration、minimal、ink。色彩、笔触、时代感、镜头距离保持连贯，不必增加风格库。
- 角色卡：`character_id`、叙事角色、必要年龄段、发型、衣着基调、固定道具及不可改变项。区分正文明确设定与为连续性设计的中性属性；后者不回写文章、不当成真人事实。
- 场景卡：`scene_id`、室内外、时间、光线、空间关系、地点模糊程度、主要道具。不要凭“电影感”添加原文没有的伤情、冲突或象征人物。
- 状态变化：按插入点记录服饰、道具与站位允许发生的变化，不能让终场物件提前出现。

将相同角色锚定短语、场景和风格约束注入每张实际请求，不只保存在总方案中。人物较多时用明确位置与衣着区别，避免同色同脸；不为了固定脸把文章未提供的身份变成现实主张。

首张检查后，将实际采用的中性外观补记为本篇视觉基准；仅有“成年人、短发、蓝灰上衣”等宽泛描述仍可能产生明显外观变化。后续逐张与已确认基准比较，发现年龄感、面貌或体型突变就拒用，不能以“衣服颜色相同”判定连续性通过。

只有工具明确支持参考输入，且参考图为已授权的虚构图时，才复用已检查的基准图。按需在配图说明注明所用参考图及用途，不默认读取原案真人照片。局部重画优先用同一基准，避免连续用新图作为下一张基准而累积偏差。无参考能力时用文字约束并披露“不能保证跨图同脸”。

检查每张角色的年龄感、面貌、体型、衣着、关键道具及画风；保留发现的偏移与实际修正。接近的文字 prompt 不等于已经验证一致性。明显影响叙事的漂移标记 rejected，仅重画指定图；不能通过挑最像的一张宣称所有图稳定。
