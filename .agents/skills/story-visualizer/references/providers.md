# 生图后端与有限调用

不自带 API 客户端、账号或安装流程。优先用户指定的可用后端，否则使用当前宿主的原生生图工具；独立服务只在已配置、使用范围获准时使用。不能因一次失败擅自换供应商、安装依赖或开通 API。

## 调用前

从实际接口确认能否输出图片、接受参考图，以及比例是精确参数还是仅 prompt 请求。模型名、尺寸或费用未知就明确未知，不推断免费。不生成能力探测图片；用本次所需的真实图完成首次调用。

在 `配图说明.md` 中简述计划图数（最多四张）、哪张兼作封面，以及必要后端/费用信息。不创建能力表 JSON 或独立日志。仅图像文件落盘后才能说已生成，实际打开检查后才能说已检查。

## 生成与保存

按工具真实参数调用，prompt 在本次执行中组织与复用，不默认另存文件。只发送可公开视觉描述及获准的虚构参考图，不发送全文、内部路径、创作记录或凭证。参考图先实际查看，不能编造工具不支持的参数。

先生成兼作封面的图，再生成其他正文图；封面复用该文件，不多调用一次。默认每张一次实际调用。文件从宿主返回位置复制到任务的 `图片/`，保留正确后缀；仅远程链接或空文件不算成功，不创建假 PNG。

失败或图意明显不符时，在同一配图说明记为失败／拒用，继续可做的其他图，不自行反复重试、重画或更换风格。用户后续指定补图或重画时，再只处理指定项，保留成功图。

无工具、费用或使用权限未解决时仍可交一份配图说明，明确“图片未生成”及原因；只暂停受阻调用，不重写文章，不把计划说成实际生图结果。
