# 起稿决定与自审边界维护

日期：2026-10-26（Asia/Shanghai）。用户授权按本轮讨论维护 Skill，重点是减少逐篇评分补救、改善起稿与现有自审，不重写已有故事。工作基于 `main` 上已有的未提交修改；本轮开始状态及修改前快照另行保存，不用 Git HEAD 冒充本轮基线。

## 规则有效性检查与取舍

| 原有内容 | 判断 | 本轮处理 |
|---|---|---|
| 故事规范已经要求愿望、阻力、应对与选择 | 方向有效，但宽泛词容易停在提纲说明；不能因为一次评稿就宣称整套起稿方法失效 | 将起稿决定具体到从对方要什么、对方要保住什么、行动改变哪项安排；已有写法可直接写，不再要求额外提纲 |
| 关键场景试写只强调方向和方案差别 | 可以提前检验昂贵的情节问题，但不能每篇强制多方案 | 明确关键应对尚不清楚也可先试；试写要解决这个缺口，成立的场景复用，不新增阶段审批 |
| 阅读体验列维度、再列相近诊断表，多处强调结构、选择和收束 | 有用的诊断被重复清单稀释，缺少从发现到编辑决定的明确区别 | 合并为编辑决定与按信号回查两张表；可定位缺陷在授权内修，审美备选不自动执行，无依据可不改 |
| 文风编辑再次提出结构缺陷 | 应保留发现新问题的能力，不能另做一遍结构诊断 | 直接复用阅读体验的判断依据，结构问题回交；当前阶段修用笔与表达 |
| 自审已有停止条件，但评价可滑向角色化打分 | 同一模型的另一种评语不等于新证据，分数不是成熟度或重写门槛 | 入口明确不设评分环节、固定改写轮次或达标分；用户明确要评分时仍可给主观判断 |
| 事实、用途、取材、范围及只读边界 | 与文学偏好不同，不能因减少编辑负担而放松 | 保持本轮开始时的规则，不用文学评分替代这些检查 |

本轮实际修改 Skill 内的入口、`story-craft.md`、`reader-experience.md`、`natural-voice.md` 四份文件。分析、写作、最终内容审校、维护来源及 UI 元数据均未再改动。README、MVP 与架构说明同步当前行为；没有架构、技术栈、依赖或交付文件类型变化。

Skill 全部 Markdown 按字符计数从本轮前的 27628 到 26894，减少 734；主要缩减来自阅读体验中重复的列表。文件长度只说明规范体量，不能推导 token 成本、时间或文学效果。

## 固定任务与隔离执行条件

协议及新合成输入见 [comparison-cases.md](comparison-cases.md#起稿与自审的维护对照2026-10-26) 与 [story-review.md](fixtures/story-review.md)。请求在修改 Skill 前固定；A、B 分别使用修改前后完整快照，不以旧 Git 提交替代已经存在的工作区版本。两个执行者不继承本轮讨论，未提供预期答案、观察判据、另一个执行者产物或旧故事。

每个执行者在自己的上下文完成 R1 审查与 R2 创作，两项不是分别独立冷启动。两组使用相同请求、输入与环境能力，模型未单独覆盖，采样参数未取得；这是单次行为对照，不是严格受控实验或独立读者盲测。材料由维护者拟定且已用于开发，不称未见测试。

快照、输入副本、请求原文及首次产物保存于被忽略的 `outputs/2026-10-26/起稿与自审维护/v01/`。正常自审属于首次交付的一部分，不能把交付后的修订冒充首次结果。维护者须全文核对实际产物，不仅采用完成声明。

## 实际产物核对

两组均已完成。维护者全文读取 A、B 的 R1、R2 正文、创作记录及执行记录，回查合成输入和相同请求，并核对实际文件集合。

| 任务 | A：修改前 | B：修改后 | 可确认范围 |
|---|---|---|---|
| R1 识别具体缺口 | 指出退出表态到共同付租缺少承接，不将其直接判为不可能 | 同样定位安排形成的缺口，并指出反悔、默契或替人决定仍需信号区分 | 两组都能区别缺少眼前决定与未交代余生；没有自动指定情节答案 |
| R1 保护平静故事 | 接受院中相处的完整性，拒绝将反转、成长、解释全部动机变成门槛 | 同样未发现须修缺陷，将更戏剧化写法留作另一方向 | 两组均只交报告，没有分数或替代稿；不是新版独有能力 |
| R2 人物与行动 | 两人互相为桌子找用途，后来接受接收者会改作工作台的条件，并协助拆桌 | 一人关注如实交接，一人仍想擦干净，随后量尺寸、拆装、送到接收者处 | 具体需要、应对和去向能从正文理解，均未靠反派或成长结语完成任务 |
| R2 自审处理 | 记录在首次交付内修了住处指向、表达和一处用回顾代替送桌决定的段落 | 顺读后保留正文，没有为了展示自审而生成改前后对照 | 实际交付符合范围；编辑过程细节来自各自记录，不把这些记录当作独立质量评测 |

A《搭把手》的兴趣较多落在接受桌子被改作别的用途与协助拆桌，B《桌子还在》较多落在交接细节和桌子搬走后的不便。两篇提供可供阅读的不同安排，维护者没有据此判 B 更好，也不因为 B 未改稿就认定它质量更高。两次起稿均已有路线，没有证明新增的“关键应对不清楚时先试写”条件产生收益。

这组材料下，旧版已能完成主要行为，新版同样成立；单次样本不能把差异归因于规范。决定保留本轮的重复内容压缩与起稿、自审边界澄清，不再从这两篇增加新的创作指标；文学收益继续待实际阅读反馈。

## 局限与后续

行为对照只观察能否识别具体缺陷、避免因偏好制造改写任务，以及在善意题材中完成具体应对。它不能证明所有初稿都会更好、文学质量稳定提高或修改负担减少。尚无用户对两篇新故事的隐藏版本比较、阅读偏好与负担反馈。

旧版已经能完成的行为不继续累加同义规则。本轮保留规范压缩、起稿决定与审查边界的明确化；不据此添加更多必须有冲突、反转、成长或损失的指标。未来规则若只增加解释和流程负担，或磨掉已成立的作品取向，应收窄或撤回；日常创作不必重跑维护对照，也不必另找“资深作家”评分后才能交付。
