# 去模板腔编辑更新与验证

日期：2026-10-23（Asia/Shanghai）。对象：`.agents/skills/story-insight/`。

## 触发、范围与验收边界

用户反馈现有 Skill 能写出不错的故事，但 AI 味明显，要求检索 GitHub 后同意继续采用分层编辑方案。本轮更新自包含的 Skill 规范，并用既有独立虚构样本 S06-v02 另存修订版 S06-v03，保留全部基线。已有私人稿件、源文路径及故事对照只留在被忽略的 `outputs/`；本报告不复制私人原稿或派生故事正文。

本轮目标是让后续执行者能够定位具体机械感、在授权内改稿并留下可审阅的对照。由同一执行者完成修改和自审，没有独立 Agent、额外模型调用、实际读者实验或检测器测试；不将元数据通过或个人判断写成“老读者无法辨认”。

## 规则与来源

- 新增按成稿阶段读取的 `references/natural-voice.md`：检查故事代讲结论、机械用笔及人物和叙述声音，要求定位缺陷、适量对照和改后顺读，不要求每层都有问题。
- 将其接在阅读体验修改之后、内容边界复核之前；同步入口、故事规范、审校、UI 提示词和项目说明。起稿时只确定说话位置，不先加载全部细项压制写作。
- 普通去味保留既定事件、动机、选择、结果与关键揭示顺序；审查只报告，已有改稿授权连续执行。涉及新结构时按已有授权判断，未获授权的部分单列，不重复索取已给的许可。
- 防止反向模板化：不设置禁词表、句长比例、删减率、强制支线或悲剧；允许心理直写、自然停顿、普通句子和有功能的重复。事实、归因、限定和作者样本不因去味丢失。

固定来源及取舍位于新规范末尾：`sepia` 的 `narrative-pass`（`d9b292c1ec8daa893e48dd60ccc07d226a75404c`）、`oh-story-claudecode` 的 `story-deslop`（`74080143dd1ac9a39a930fafd99a0dbbe61b946a`）、`creative-writing-skills` 的 `style-analysis`、`voice` 和 `failure-modes`（`fec5020a91dddd089d74a00a2d7b87f15a919ae4`）。相关文件已实际阅读，前两者本轮另核对固定提交。只借鉴方法，没有复制示范、安装项目或引入其脚本、多 Agent 与运行服务。

StoryScope 提供叙事特征的分类研究，不能证明这些改稿规则的效果。外部语料与统计没有转换成中文故事的验收阈值。

## 合成边界小例

以下是本轮专为检查编辑取舍新写的公共教学片段，不来自私人素材，不是用户案例；由同一执行者手动应用规范，没有独立评测含义。

1. **真实反驳保留。** “会议定在周四，不是周三。邀请函上的日期要改。”无需只因出现否定对比而改写；两天的差别与修改要求都是独立信息。
2. **心理直写保留。** “第二天她还在生气，没有回那封信。”可在过渡中直写情绪，不强制替换成喉头、指尖或杯子动作，不凭空增加身体描写。
3. **事实与不确定性保留。** 合成原句“根据团队提供的记录，5月试用的40人中，8人表示可能继续使用；尚未核实实际续费。”编辑为“团队记录称，5月试用的40人中，8人表示可能继续使用，实际续费尚未核实。”保留月份、分母、人数、归因、意向与未核实状态；不能改成续费率或已续费人数。
