# 指定素材与独立故事的关联检查

日期：2026-10-23（Asia/Shanghai）。对象：`.agents/skills/story-insight/`。

## 触发与范围

用户指出 S02 派生故事与指定对话稿关联不清，并授权修正 Skill 与结果稿。旧版保留在被忽略的任务输出目录；本轮生成 v02，不把私人原稿或派生故事复制到此报告。

问题在于规则强调一般议题与不回放原案，却没有要求说明新人物的行动如何承载所选困境。原审校未检出主题相同而起因已变的偏移，不能继续把该样本列为取材关联通过。

## 规则修改

- 指定稿件生成故事时，默认保留选定、有依据的关系或选择困境；用户明确只借主题时允许自由创作。
- 在原有创作记录内说明原文依据、创作理解、保留及重建部分，不新增必交文件。
- 区分一般关系张力与可识别的人物网络及具体经历链，分别检查关联过弱和原案回放。
- 检查新增起因及年龄、身份转换是否改变受伤原因、依赖、求助条件或选择成本。
- 普通两难与侵扰分开处理，不为对称立场开脱伤害，也不将勇敢或原谅作为得到帮助的前提。

## 内容回放

本轮重新全文读取 S02 的 50 行输入，按更新后的规则先记录保留与重建的对应，再完整生成并自审 S02-v02。对旧版本只回查与已指出偏移有关的起因及关键段落。另全文重读 S06-v02 及其创作记录；S06 的原素材沿用已有阅读记录，本轮未重新通读，因此不把此次回看当作新一轮来源核验。

| 样本 | 实际观察 | 判断范围 |
|---|---|---|
| S02-v01 | 保留了议题和回应转向，但新增起因使人物为何受伤及主线发生偏移 | 保留为关联不足的基线，未改写原文件 |
| S02-v02 | 写作前区分原文行为、创作推断及新设定；人物继续争取关系、补充后帮助方式改变，进入了关键场景与选择 | 本轮实际新生成并自审；具体情节独立，关联与好读仍待用户判断 |
| S06-v02 | 既有稿保留了诉求与初始办法的差距、尝试与决定的区别，新增人物的分歧没有被冒充为原稿事实 | 规则回看不要求逐场复演原案；原有用户肯定仍只对应该版本，未生成其新版 |

检查时将原文未明确说明的内心保持为推断或新人物设定，没有为了加强关联补写源人物动机。新故事同时检查具体经历的独立性，不以回到原人物网络、原话或事件链证明关联。

上述工作由同一执行者完成，不是独立 Agent 测试。没有另调用模型服务、做读者实验或根据文本自审推导留存效果。
