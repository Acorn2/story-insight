# 独立故事写作更新与验证

日期：2026-10-23（Asia/Shanghai）。对象：`.agents/skills/story-insight/`。

## 触发与范围

此前用户连续指出样例缺少故事、暴露原来源、只处理一方叙述，以及建议奏效后人物问题被过早抹平。独立虚构样本 S06-v02 得到用户“可以，非常不错”的反馈，本轮用户明确要求把方法更新到 Skill。

该反馈只对应这个样本的阅读效果，不等于发布许可或整套 Skill 的稳定性验收。本报告不收录原稿、人物资料、私人路径或样本故事正文；已有任务产物保留在被忽略的 `outputs/`，未复制到公共示例。

## 本轮修改

- 入口支持明确标示的独立虚构故事。用户要求参考素材另写故事时，不默认缩成假设片段；事实解答与仅选题仍沿用原任务范围。
- 分析阶段明确读取诉求、回应、补充、建议调整或错位，以及未决问题。原对话用于理解互动，不把主播回复变成标准答案。
- 新增按需读取的 `story-craft.md`：区分人物诉求与尝试实际解决的问题，建立合理立场、场景因果、关键对白、选择及后果。没有固定分幕、强制反转或悲剧要求。
- 真人材料禁止无依据补写；独立虚构允许完整创造，并明确标示。现实断言另行核查，虚构结果不能用作效果证据。
- 阅读体验与内容审校补上诉求错位、工具化配角、突然消失的冲突，以及开放结尾回避选择等检查。同步项目范围、使用说明与 UI 提示词。

## 文本回放与边界推演

这是同一执行者的文本审查，不是独立 Agent 测试或新一轮完整生成实验。

重新全文阅读已获反馈的 v02，并结合既有 v01 创作记录作编辑回放：

| 检查项 | 观察结论 | 证据范围 |
|---|---|---|
| 诉求与解决的问题 | 尝试结果与个人意愿分别处理，未用一个成功替所有人作决定 | v02 正文与既有记录；不是对现实建议的效果验证 |
| 人物立场 | 双方都有继续或改变的理由，也承担不同后果 | 当前执行者顺读，不能代表独立读者 |
| 因果与场景 | 尝试的机会和承诺在关键选择前有交代，重要分歧通过场景展开 | 文本内部一致性检查 |
| 完整性 | 核心选择发生，后续责任有安排，未把所有关系和未来写成已解决 | 选择与结尾的对应检查 |
| 启发与幽默 | 由人物行动、反应与生活观察承载，没有追加主题总结 | 只报告文本特征；效果反馈只限用户已认可的该版本 |

另对以下请求作静态规则推演，没有生成额外的完整文章：

| 条件 | 当前入口与规范的处理 |
|---|---|
| 明确要求参考素材另写故事 | 完整分析互动，再创建并标示独立虚构；不复演原案 |
| 仅要求把事实文章改得生动 | 沿用事实边界，不因“有趣”自动添加虚构情节；检查时收窄了入口的此项触发条件 |
| 只要求分析或选题 | 停在分析与选题，不因故事规范存在就自动成稿 |
| 原稿未提供采纳或后续 | 原案分析保留未知，虚构后果单列，不能反向归给真人 |
| 虚构场景涉及专业规则或推广建议 | 核查影响情节或现实判断的规则，不能用故事成败充当效果证据 |
